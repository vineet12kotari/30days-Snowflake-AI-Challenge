## 📌 Overview

This repository documents my journey through the **#30DaysOfAI challenge**, a structured 30-day, hands-on learning initiative focused on building **AI-powered applications** using **Streamlit** and **Snowflake Cortex AI**.

The challenge progresses from **foundational AI concepts** to **advanced, production-ready AI systems**, with daily implementations, documented learnings, and visible outputs.

This repository is maintained as both:
- 📘 A **learning log**
- 🧪 A **hands-on AI project portfolio**

---

## 🎯 Goals of the Challenge

- Build interactive AI applications using **Streamlit**
- Work with Snowflake data using **Snowpark**
- Understand and implement **LLM calls**
- Handle **streaming responses** and **caching**
- Design **chat-based AI interfaces**
- Manage session state and application context
- Build **RAG (Retrieval-Augmented Generation)** systems
- Explore **multimodal AI**
- Design **autonomous AI agents**
- Apply best practices for scalable AI apps

---

## 🧭 Challenge Roadmap

### 🔹 Week 1 – Foundations

## 📂 Repository Structure
```
30days-Snowflake-AI-Challenge/
├── app/               # Streamlit applications (day1.py - day30.py)
├── md/                # Detailed lesson documentation (day1.md - day30.md)
├── toml/              # Configuration files for specific lessons
├── pyproject.toml     # Python dependencies
└── README.md          # This file
```

Each day includes:
- **📱 App file** (`app/dayX.py`) - Complete, runnable code
- **📖 Documentation** (`md/dayX.md`) - Step-by-step explanations
- **💡 Key concepts** - What you'll learn and why it matters


## 🛠️ Technologies

- **[Streamlit](https://streamlit.io)** - Fast, beautiful web apps for ML and data science
- **[Snowflake Cortex AI](https://docs.snowflake.com/en/user-guide/snowflake-cortex/overview)** - LLM functions and AI services
- **[Cortex Search](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-search)** - Semantic search service
- **[Cortex Analyst](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-analyst)** - Natural language to SQL
- **[Cortex Agents](https://docs.snowflake.com/en/user-guide/snowflake-cortex/cortex-agents)** - Autonomous AI agents
- **[TruLens](https://www.trulens.org/)** - LLM evaluation and observability
